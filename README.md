# Martinova knižnica

Osobná digitálna polička kníh uložených v Google Keep. Obsahuje vyhľadávanie,
odkazy na Martinus a lokálny archív prečítaných titulov.

## Lokálne spustenie

```bash
pnpm install
pnpm exec vinext dev
```

## Zostavenie

```bash
pnpm exec vinext build
```

Archív prečítaných kníh sa ukladá iba v danom prehliadači (`localStorage`).
